# Dave's Tunes

A songbook app for phone or tablet: song list with search, capo and starting chord ("1-C") at the top of each song, hands-free auto-scroll, and adjustable text size and scroll speed. Songs are added by typing or by scanning a paper sheet (read on the device with Tesseract, in `ocr/`).

It is a plain static site. Install it from the browser's "Add to Home Screen"; it then works offline.
